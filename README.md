# Rawnaq 🚀

Rawnaq — Lightweight, performance-first Elementor & Gutenberg widgets for WordPress.

## 📦 Core Free Modules

1. **Hub Diagram**: Interactive Hub & Spoke workflow diagram (PNG/SVG export).
2. **3D Tilt Card**: Interactive parallax tilt cards with optional flip/back-face.
3. **Scroll Sync Timeline**: CSS scroll-driven timeline with JS fallback.
4. **Floating Dock Menu**: macOS style floating dock + WhatsApp Contact Mode.
5. **Flow Chart**: Org/process/freeform flowchart + WP Users org tree + PNG/SVG export.
6. **Scroll Progress + TOC**: Real-time reading progress bar + smart floating Table of Contents.
7. **Bento Grid**: Interactive marketing bento layout with Elementor live resize + Gutenberg InnerBlocks.
8. **Scroll Story Chapters**: Cinematic scrollytelling with pinned media and video sync.
9. **Smart Form**: Multi-step lead form with email receipts, WhatsApp redirect, and Mailchimp/HubSpot CRM delivery.
10. **Case-Study Grid**: Dynamic portfolio grid with multi-filter chips, modal gallery lightbox, and AJAX pagination.
